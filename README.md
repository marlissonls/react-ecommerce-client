# React Ecommerce Client

Frontend do projeto Ecommerce desenvolvido com React, TypeScript e Vite.

## Tecnologias

- React
- TypeScript
- Vite
- React Router
- Material UI
- Tailwind CSS
- Axios
- TanStack Query
- React Hook Form
- Zod

## Requisitos

- Node.js
- npm

## Instalação

```bash
npm install
```

## Executar em desenvolvimento

```bash
npm run dev
```

## Build de produção

```bash
npm run build
```

## Configuração

As configurações públicas do frontend devem ser definidas conforme o ambiente.

Não armazenar senhas, tokens secretos ou chaves privadas no código ou nas variáveis expostas ao navegador.

## Observações

Este projeto corresponde à aplicação frontend React do Ecommerce.
